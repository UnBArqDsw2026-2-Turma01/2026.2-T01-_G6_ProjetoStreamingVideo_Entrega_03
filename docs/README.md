**Ainda não há implementação de padrões nesta estrutura inicial.** Quando o código for acrescentado, cada subequipe deverá registrar dependências, comandos e vídeo de execução em seu relatório.

Para visualizar apenas a documentação localmente:

```bash
python3 -m http.server 8000 --directory docs
```

Acesse `http://localhost:8000`. A documentação utiliza Docsify carregado por CDN.
