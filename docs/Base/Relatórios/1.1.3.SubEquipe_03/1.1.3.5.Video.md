### Roteiro do Observer (Moderação)

| Tempo | Etapa | O que mostrar na tela | Fala sugerida |
| :---: | :--- | :--- | :--- |
| **00:00 - 00:45** | **Apresentação** | Arquivo `1.1.3.1.ModelagemObserver.md` | *"Olá, somos da SubEquipe 03 de Desenho de Software (UnB Gama - Profa. Milene Serrano). Nosso foco nesta entrega é a aplicação de Padrões GoF Comportamentais à plataforma de streaming. Apresento aqui o Foco 1 da subequipe: a modelagem e execução do padrão GoF Observer aplicado ao ciclo de vida da live e ao pipeline reativo de moderação de segurança."* |
| **00:45 - 01:30** | **Fundamentação Teórica** | Diagrama de Classes e `src/patterns/observer/interfaces.ts` | *"No Slide 53 da Profa. Milene temos o Observer com `attach`, `detach`, `getState` e `notify`. O nosso `StreamChannel` atua como Sujeito Concreto. Criamos observadores especializados desacoplados para AutoMod de chat, IA de visão computacional para conteúdo sensível e detector de áudio para DMCA, além de delegar o laço de envio via GoF Strategy."* |
| **01:30 - 02:45** | **Demonstração Prática (Demo ou REPL)** | Terminal rodando `npm run demo` ou `npm run interactive` | *"Ao rodar `npm run demo` ou o console interativo `npm run interactive`, demonstramos os canais reais: Sorashina Sopia no YouTube, Dima Wallhacks na Twitch e eskimozin na Kick. Vemos na tela o envio de mensagens barradas pelo AutoMod com entropia de Shannon, o silenciamento automático por DMCA e a aplicação de Content Warning 18+ por análise de imagem."* |
| **02:45 - 04:00** | **Iniciativa Extra (Benchmark)** | Terminal rodando `npm run benchmark` | *"Na Iniciativa Extra de concorrência, simulamos 2.000 seguidores ativos conectados na Twitch. Mostramos que no laço síncrono linear a thread do criador trava por mais de 10 segundos, enquanto na nossa estratégia assíncrona concorrente com Worker Pool a thread é liberada em 6 milissegundos, com speedup de mais de 116 vezes."* |
| **04:00 - 04:30** | **Testes Automatizados e ADR** | Terminal rodando `npm test` e visualização do ADR-003 | *"Comprovamos a estabilidade com 13 testes unitários automatizados com 100% de sucesso e registramos a decisão arquitetural formalmente no ADR-003 citando Gamma, Larman e Sommerville."* |

### Pré-requisitos e comandos

```bash
cd docs/Base/Relatórios/1.1.3.SubEquipe_03/codigo
npm install
npm run interactive  # console interativo REPL com comandos em tempo real (Iniciativa Extra)
npm run demo         # demonstração automatizada de streaming e moderação
npm run benchmark    # teste de carga comparativo com 2.000 espectadores (Iniciativa Extra)
npm test             # 13 testes unitários automatizados nativos
```
